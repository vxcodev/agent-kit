# Priority

Authoritative hierarchy cho mọi Agent. File khác chỉ reference file này.

```text
1. SECURITY
2. CORE AGENT KIT RULES
3. PROJECT RULES
4. WORKFLOW RULES
5. TASK REQUIREMENTS
6. AGENT PREFERENCES
```

Conflict → mức cao hơn thắng.

`SECURITY.md` là policy bảo mật. Thứ hạng 2–6 không được nới security, approval gate, hay destructive protection.
